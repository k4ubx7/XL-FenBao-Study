粉包学习记 1.1
================

Windows 用法
------------
1. 解压后整体保留“粉包学习记”文件夹，建议放在 D 盘等空间充足的位置。
2. 双击“粉包学习记.exe”。
3. 粘贴抖音分享文案或其他公开视频链接。
4. 点击“开始下载”，等待状态变成“已完成”。

Mac 用法
--------
1. Apple 芯片（M1 及更新型号）选 macos-arm64；Intel 芯片选 macos-x64。需要 macOS 13 或更新系统。
2. 打开 DMG，将“粉包学习记”拖到“应用程序”，再双击启动；ZIP 版本解压后也可拖到“应用程序”。
3. 粘贴公开视频链接，点击“开始下载”。
4. 首次打开如果被系统拦截，确认来源后在“系统设置 → 隐私与安全性”中选择“仍要打开”。此版本未通过 Apple 公证。

两个平台均已内置下载工具，无需安装 Node.js、Python 或 Homebrew。

默认设置
--------
- 画质：720p 标准
- 同时下载：2 个
- Windows 保存位置：程序所在文件夹里的 downloads
- Mac 保存位置：用户“下载”文件夹中的“粉包学习记”
- 每个视频单独建立一个同名文件夹
- 视频文件与文件夹使用相同的统一名称
- 不额外下载封面、字幕或元数据文件

左下角“设置”可以更改画质、同时下载数量、保存位置，以及是否在完成后自动打开文件夹。

文件夹说明
----------
- 粉包学习记.exe：双击启动
- downloads：默认的视频保存位置
- data：设置、任务记录、日志及应用自己的隔离浏览器数据
- resources：程序需要的第三方组件，请勿删除

Windows 是便携版，不需要安装。移动时请移动整个文件夹，不要只复制 exe。
Mac 的设置、任务记录和隔离浏览器数据保存在 ~/Library/Application Support/粉包学习记；替换应用时可保留这些数据。

抖音说明
--------
请先安装 Google Chrome 或 Microsoft Edge。部分抖音页面需要在应用弹出的独立浏览器窗口中完成登录。该窗口使用应用自己的隔离配置，不读取日常浏览器账号。登录 Cookie 保存在应用数据目录的 douyin-browser 中，不要把个人数据目录发送给他人。

注意
----
本程序只用于保存你有权下载的公开内容，不会绕过登录、付费、地区、DRM、验证码或其他访问限制。网站规则改变、链接失效或网络异常时，任务可能失败；可以在任务右侧查看原因并重试。
